# 安全与提交前检查清单（safety-checklist）

每次「汇报前」或用户要求提交前，过一遍。

## 必须遵守

- [ ] 未点击「提交 / 预览并提交」
- [ ] 奖项、成绩、证书、项目均来自用户档案或用户当次口述，**无编造**
- [ ] 身份证、手机未写入仓库、日志、临时 md/json
- [ ] 截图未包含完整身份证号（或已打码/裁切）
- [ ] 验证码 / 滑块 / 短信 / 签名 / 文件上传由用户完成
- [ ] 政策类单选（届别、调剂、亲属、渠道）已由用户确认

## 建议确认

- [ ] 已点「暂存」（若有）
- [ ] 获奖级别与时间与档案一致
- [ ] 教育起止与学历层次正确
- [ ] 邮箱、手机无空格/全角字符
- [ ] 自我评价经用户改过再用

## 出现这些情况时停止

| 情况 | 动作 |
|------|------|
| 表单要求填写档案没有的事实 | 问用户，禁止猜 |
| 连续 2 次点击/填充失败 | 停下，报告页面状态 |
| 触发人机验证 | 请用户完成，不重试自动过验证 |
| 用户要求「直接交了」 | 拒绝自动提交，请本人确认 |

## 隐私边界

- 证件号只在表单控件 value 中出现  
- 对话里可写「已填身份证」，不复述完整号码  
- 任务结束后不要把含证件号的 profile 再复制一份到新路径
