# 网申填表助手（job-app-filler）

把「读档案 → 开表单 → 分栏填写 → 人工确认」固化成可重复流程。目标是**少打字、不误交、不泄露**。

## Important

1. **永不自动点「提交 / 预览并提交」**。填完停在预览或暂存，请用户自己确认提交。
2. **禁止编造**奖项、成绩、证书、实习。档案没有的字段只询问用户，不瞎填。
3. **敏感信息**（身份证、手机、紧急联系人）仅用于本次表单填写；不写入聊天外的多余文件；截图避免整页完整证件号。
4. 验证码、短信码、滑块、手写签名、本地选文件上传 — **一律请用户完成**，不要尝试破解。
5. 同一逻辑连续失败 **2 次** 就停下汇报，不要无限重试。

## Instructions

### Step 1 — 收集任务输入

向用户确认（缺一则问，一次问完）：

| 项 | 说明 |
|----|------|
| 岗位 URL | 网申表完整链接 |
| 档案路径 | 默认：用户工作区中的简历档案；仓库模板见 `assets/profile.example.yaml` |
| 是否已登录 | 已登录则优先接管现浏览器 |
| 要填哪些栏 | 默认：个人信息、教育、证书、获奖、项目/实践；其余用户自填 |
| 期望岗位信息 | 城市/岗位/薪资等意向（档案可没有） |

若无档案：先复制 `assets/profile.example.yaml`，请用户填完再继续，**不要用假数据填表**。

### Step 2 — 加载并校验档案

读取 YAML/MD 档案，至少具备：

- 个人信息：姓名、性别、民族、出生日期、证件号、手机、邮箱、政治面貌、籍贯、现居地
- 教育：学校、学院、专业、学历、学位、起止时间、GPA/排名（可选）
- 证书列表 `certs[]`
- 获奖列表 `awards[]`：`name`、`date`（YYYY-MM）、`level`（国家级/省级/校级/其他）
- 项目/实践 `projects[]`：名称、角色、时间、一句话摘要

缺关键项 → 列出缺失清单请用户补，再进入 Step 3。

### Step 3 — 打开浏览器与页面

按顺序尝试：

1. **接管已打开的 Edge/Chrome（推荐）**  
   - 若用户已按调试模式启动：连接 CDP `http://127.0.0.1:9222`  
   - 否则请用户关闭浏览器后执行（示例，路径按本机调整）：
     ```text
     msedge.exe --remote-debugging-port=9222
     ```
     再连接 CDP。
2. **Playwright 新开**  
   - 优先 `channel=msedge` 打开岗位 URL  
   - 沙箱/权限失败时，指导用户手动打开 URL，再 attach
3. 打开后 `snapshot`（或等价可访问性树）确认是网申表，不是登录墙。登录墙则请用户登录。

### Step 4 — 按栏目填写（北森类映射）

详细字段对照见 `references/form-mapping.md`。填写顺序建议：

1. 个人信息  
2. 教育经历  
3. 证书  
4. 获奖情况（批量，见 Step 5）  
5. 项目 / 在校实践  
6. 其他文本框（自我评价等，生成草稿后请用户改）

操作要点：

- 用 snapshot 的元素 ref 填充/点击，避免盲猜选择器  
- 复杂下拉：先在搜索框输入关键词，再点选匹配项  
- 单选/复选：按用户确认的选项点选；不确定就问  
- 「是否接受调剂」「是否 2026 届」等政策题：**问用户**  
- 有「暂存 / 保存」优先点暂存；没有就填完停下

### Step 5 — 获奖情况批量循环

对 `awards[]` 按 **国家级 → 省级 → 校级 → 其他** 排序，逐条：

1. 点击「添加获奖情况 / 新增」  
2. 填奖项名称、获奖时间、获奖级别（下拉能搜则搜）  
3. 若有「颁奖单位」等档案字段则填，否则留空或问用户  
4. 循环直到主要奖项填完（可先填省级及以上，问用户是否继续校级）

### Step 6 — 人工关口（必须停下）

以下任一出现时，停止自动操作，用简短说明请用户完成：

- 图形验证码 / 短信验证码  
- 滑块、点选、无感验证  
- 手写签名 / 电子签  
- 上传证件照、证书、成绩单（请用户本地选择文件；可告知期望文件名）  
- **预览并提交**

### Step 7 — 汇报

用短表汇报，不要贴出完整证件号：

- 已填写栏目  
- 跳过 / 留给用户的项  
- 待用户：验证、上传、确认提交  
- 若有暂存：说明已暂存  

## Examples

**用户**：帮我填这个北森网申 https://…/apply/… 档案在 `D:/…/profile.yaml`

**做法**：确认已登录与栏目范围 → 读档案校验 → 连接浏览器 → snapshot → 按 Step 4–5 填写 → 遇验证码停下 → 汇报「已暂存，等你验证后自行提交」。

**用户**：获奖太多了，只帮我把获奖栏填完

**做法**：只读 `awards[]`，只操作获奖的「添加」循环，填完列出奖项清单让用户核对。

## Troubleshooting

| 问题 | 处理 |
|------|------|
| 连不上 CDP 9222 | 请用户完全退出浏览器后带调试端口重启；确认无其他实例占用 |
| Playwright 打开空白/拦截 | 改 `msedge` channel，或请用户手动打开后 attach |
| 下拉选不中 | 先输入关键词过滤再点；不要用不存在的值硬设 |
| 表单结构每次不同 | 以当前 snapshot 为准；映射表只是启发式，不硬编码选择器 |
| 用户催「直接提交」 | 仍拒绝自动提交，说明需用户本人确认与可能的人机验证 |

## Out of scope

- 识别或破解验证码/滑块  
- 伪造奖项、学历、证书  
- 智联/BOSS 等其它站点的深度适配（可按 form-mapping 扩展）  
- 自动点击最终提交
